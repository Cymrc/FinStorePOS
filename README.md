# 🛒 Sari-Sari Store Point of Sale (POS) System

A modern web-based **Point of Sale (POS) System** developed using **HTML, CSS, and Vanilla JavaScript**. This application simulates a cashier terminal for a Filipino sari-sari store, allowing users to manage customer purchases, calculate totals automatically, record transactions, and monitor sales performance—all within the browser using Local Storage.

---

## 📌 Project Overview

The Sari-Sari Store POS System is designed to streamline the checkout process for small retail businesses. It provides an intuitive interface for cashiers to search products, manage customer orders, process payments, and maintain transaction history without requiring a backend database.

This project demonstrates front-end development concepts, dynamic DOM manipulation, local storage persistence, and responsive user interface design.

---

## ✨ Features

### 🛍 Product Catalog
- 50 grocery products
- Product images
- Product ID selection
- Search products by name or ID
- Category filtering
- Quick product selection

### 🛒 Shopping Cart
- Add products
- Increase or decrease quantity
- Remove products
- Automatic subtotal calculation
- Live cart updates

### 💰 Checkout System
- Cash payment input
- Automatic total calculation
- 10% discount for purchases above ₱1,000
- Automatic change computation
- Customer name (optional)

### 📊 Sales Dashboard
- Total transactions
- Total sales
- Best-selling product
- Top-performing category

### 🧾 Transaction History
- Save completed transactions
- Receipt preview
- Persistent browser storage
- Clear transaction history

### 💾 Data Persistence
Uses **Local Storage** to save:
- Current cart
- Sales history
- Dashboard statistics
