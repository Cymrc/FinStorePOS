## 📌 Project Overview

A modern web-based **Point of Sale (POS) System** developed using **HTML, CSS, and Vanilla JavaScript**. This application simulates a cashier terminal for a Filipino *sari-sari* store, allowing users to manage customer purchases, calculate totals automatically, record transactions, and monitor sales performance—all within the browser using Local Storage.

The system is designed to streamline the checkout process for small retail businesses, providing an intuitive interface for cashiers to search products, manage customer orders, process payments, and maintain transaction history without requiring a backend database.

---

## ✨ Features

### 🛍️ Product Catalog
- 50 grocery products
- Product images and IDs
- Search products by name or ID
- Category filtering
- Quick product selection

### 🛒 Shopping Cart
- Add products and adjust quantities (increase/decrease)
- Remove items seamlessly
- Automatic subtotal calculation
- Live cart updates

### 💰 Checkout System
- Cash payment input
- Automatic total calculation
- 10% discount for purchases above ₱1,000
- Automatic change computation
- Optional customer name entry

### 📊 Sales Dashboard
- Total transactions count
- Total sales tracking
- Best-selling product indicator
- Top-performing category display

### 🧾 Transaction History
- Save completed transactions
- Receipt preview generation
- Persistent browser storage via Local Storage
- Clear transaction history option
